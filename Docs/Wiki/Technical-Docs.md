# 기술 문서

각 GitHub Issue별 구현 내용과 사용법을 보관하는 페이지입니다.

새 기술 문서는 [기술 문서 양식](TechnicalDocument)을 기준으로 작성합니다.

## 작성 기준

각 문서는 아래 항목을 기준으로 정리합니다.

- Issue 번호와 기능명
- 구현 목적
- 주요 구현 내용
- 관련 구현
- 사용 방법
- 테스트 또는 확인 내용
- 남은 작업 또는 확장 방향
