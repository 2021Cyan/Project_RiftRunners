# #30 무기 드랍 및 장착 교체 구현

## Issue

- Issue 번호: #30
- 기능명: 무기 드랍 및 장착 교체 구현
- 담당 영역: Weapon / Interaction / Replication
- 관련 의존성: #27 PCG 무기 파츠, #28 무기 등급, #36 적 처치 보상 드랍

## 목적

바닥의 무기를 장착하면 기존 무기가 플레이어의 손에서 원래 픽업 위치까지 짧은 포물선을 그리며 이동한다. 다시 상호작용하여 교체해도 각 무기의 런타임 스탯과 현재 탄창 탄약을 유지한다. 예비 탄약은 무제한이며 별도 수량을 저장하지 않는다.

## 주요 구현 내용

1. `AGunObject::Execute()`에서 기존 무기의 데이터, 클래스, 템플릿, 현재 탄약을 저장한다.
2. `SpawnAndEquipGeneratedWeapon()`으로 새 무기를 초기화하고 장착한다. 저장된 탄약은 장착 이벤트 전에 복원한다.
3. 장착 성공 시 기존 GunObject에 이전 무기의 상태를 넣고 외형과 등급 효과를 갱신한다. 플레이어의 기존 무기 위치로 옮긴 뒤, 원래 픽업 위치까지 계산하여 `LaunchFromShop()`으로 물리 드랍한다. 이후 이동과 착지는 물리가 처리한다. 충돌이나 바운스로 실제 정지 위치는 달라질 수 있다.
4. 기존 무기가 없으면 픽업을 제거한다. 장착 실패 시 기존 무기와 픽업을 유지한다.

`AWeaponBase::GetDropData()`는 생성 당시 데이터에 현재 런타임 스탯과 조립 외형을 반영한다. 생성 무기의 등급, 파츠 이름, 레벨, 이름을 유지하며 기본 DataAsset 무기도 현재 외형과 스탯으로 드랍할 수 있다.

## 관련 구현

- `WeaponBase.h/.cpp`: 드랍 데이터 추출 및 저장 탄약 초기화
- `WeaponComponent.h/.cpp`: 장착 전 저장 탄약 전달, 기존 장착·해제 흐름 사용
- `GunObject.h/.cpp`: 서버에서 교체 처리 및 개인 픽업 재사용
- 드랍 이동은 기존 액터 이동 복제를 사용한다. 별도 메시 보간, 드랍 Multicast, 타이머, 착지 위치 강제 보정은 사용하지 않는다. 기존 상점·적 드랍 동작은 유지한다.
- `WeaponDataAsset.h`: 모든 무기 카테고리가 공유하는 `EquipSound` 설정. 기존 `FWeaponSoundSettings::Resolve()`로 목록에서 소리와 피치를 무작위 선택한다. 서버의 장착 경로와 클라이언트의 `OnRep_EquippedWeapon()`에서 WeaponPresentationComponent를 호출한다. 

## 사용 방법

기존 GunObject Blueprint와 상호작용 입력을 그대로 사용한다. 무기를 장착한 상태로 개인 픽업과 상호작용하면 두 무기를 반복해서 교체할 수 있다.

- GunObject Blueprint의 `Gun Object | Swap Drop`에서 `SwapOutwardSpeed`와 `SwapUpwardSpeed`로 비행 시간을 조정한다. 수평 거리/속도와 위쪽 속도/중력을 기준으로 0.2~0.8초를 사용하며, 실제 초기 속도는 도착 위치에 맞게 계산한다. 기존 높이 오프셋·호버는 유지한다.
- 사용 중인 WeaponDataAsset의 `Weapon | Feedback | Sound` 아래 `EquipSound`를 펼쳐 `Sounds` 목록, `Volume`, `PitchRange`를 설정한다. 고정 피치는 X/Y에 같은 값을 넣는다. 이전 단일 사운드 참조는 `Sounds` 목록에 다시 지정한다. 빈 목록은 무음이며, 2D 재생이므로 `Attenuation`은 사용하지 않는다.
- 시작 시 DataAsset으로 지급되는 기본 무기는 장착음을 재생하지 않는다. GunObject에서 장착하는 무기만 재생하며, 기본 무기도 드랍 후 다시 주우면 생성 데이터로 복원되므로 소리가 난다.
