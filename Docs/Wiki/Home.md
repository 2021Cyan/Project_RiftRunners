# 프로젝트 위키

이 페이지는 본 프로젝트의 기능 문서, 주차별 회의록, Sprint 계획을 정리합니다.

## 이슈별 문서화

각 기능은 GitHub Issue 단위로 관리하며, 구현이 완료된 기능은 Wiki에 문서화합니다.

문서에는 아래 내용을 포함합니다.

- Issue 번호와 기능명
- 구현 목적
- 주요 구현 내용
- 관련 구현
- 사용 방법
- 테스트 또는 확인 내용
- 남은 작업 또는 확장 방향

문서 목록은 [기술 문서](./Technical-Docs.md) 페이지에서 확인합니다.

## 주차 회의록

회의록은 `Docs/Meetings/WeekN.md` 형식으로 관리합니다.

회의록에는 아래 내용을 기록합니다.

- 날짜
- 참석자
- 이번 주 완료 작업
- 코드 리뷰 및 공유 내용
- 발생한 문제
- 결정 사항
- 다음 주 작업 계획

회의록 목록은 [회의록](./Meeting-Notes.md) 페이지에서 확인합니다.

## 운영 규칙

- 기능 구현은 Issue 단위로 진행합니다.
- 구현 완료 후 PR을 생성하고 관련 Issue를 연결합니다.
- 완료된 기능은 Wiki에 사용법과 확인 내용을 정리합니다.
- 회의록은 매주 작성하고 다음 Sprint 계획을 함께 기록합니다.
- Sprint 표는 GitHub Issue의 `sprint:*` 라벨 기준으로 관리합니다.
