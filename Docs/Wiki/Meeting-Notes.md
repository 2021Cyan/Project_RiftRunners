## 작성 기준

회의록은 `Docs/Meetings/WeekN.md` 형식으로 관리합니다.

각 회의록에는 아래 내용을 기록합니다.

- 날짜
- 참석자
- 이번 주 완료 작업
- 코드 리뷰 및 공유 내용
- 발생한 문제
- 결정 사항
- 다음 주 작업 계획

## 회의록 양식

```md
# N주차 회의록

## 날짜

## 참석자

## 이번 주 완료 작업
- 이름: 완료한 Issue / 주요 코드 변경

## 코드 리뷰 및 공유 내용

## 발생한 문제

## 결정 사항

## 다음 주 작업 계획
- 이름: 담당 Issue
```
